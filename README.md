# 🐾 Yolo Animal Detect

基于 **YOLOv8** 的动物识别系统，附带用户图形化界面（GUI），方便上传图像进行动物检测与可视化展示。

---

## 🔍 项目概览

| 项目         | 内容                                            |
| ------------ | ----------------------------------------------- |
| **功能**     | 检测图像与视频中的动物，支持标注框 + 可视化输出 |
| **模型框架** | YOLOv8                                          |
| **界面方式** | 图形化界面，用户可上传图片／视频进行检测        |
| **许可证**   | MIT 许可证                                      |

## 🚀 快速开始

以下是从零开始使用本项目的步骤：

### 前置要求

- Python >= 3.7  
- GPU + CUDA（若要加速推理／训练）  
- 推荐创建虚拟环境（venv／conda 等）

### 安装依赖

在项目根目录中执行：

```bash
# 使用 pip 安装依赖（假设已有 requirements.txt）
pip install -r requirements.txt
```

如果没有 `requirements.txt`，你可能需要安装以下包：

- ultralytics（YOLOv8 所用包）
- opencv-python
- numpy
- matplotlib
- PyQt5 或其他界面库

### 获取预训练模型

将 `pretrained/` 下的模型权重准备好。例如：

```
pretrained/
├── yolov8s.pt
├── yolov8-...（其他版本）
```

### 标注数据格式

- 在 `animal_yolo_format/` 中，包括你需要训练／评估用的标注格式脚本／工具。
- 确保你的标签（`.txt` 或 `.yaml`）符合 YOLOv8 的要求：每个目标一行，含类别编号 + bbox 坐标（通常是相对格式 x_center, y_center, width, height）。

## 🎯 使用教程

### 使用 GUI 进行检测

1. 启动 GUI 应用
2. 在界面中上传 / 选择图像或视频文件
3. 设置检测参数（如置信度阈值、类别等）
4. 点击“开始检测”，等待结果显示 + 可视化
5. 可将带有边框标注的图像／视频保存到指定输出目录

### 命令行推理（非 GUI）

如果你想跳过界面，直接在命令行部署：

```bash
python detect.py --weights pretrained/yolov8_animals.pt --source path/to/image_or_video \
   --conf 0.25 --classes 0,1,2  # 根据已有类别编号
```

参数说明：

- `--weights`：模型权重文件路径
- `--source`：输入图像／视频路径或设备如 `camera`
- `--conf`：置信度阈值
- `--classes`：指定类别检测

## ✅ 注意事项与建议

- **类别不一致**：如果你的类别（动物种类）与预训练模型不一致，要确保类别名称与标注一致。
- **图片分辨率**：高分辨率图像虽然能提升精度，但占用内存／算力多。推荐统一缩放／裁剪。
- **模型版本**：YOLOv8 的不同版本（n / s / m / l / x）对速度 vs 精度权衡不同，按需选择。
- **GPU 支持**：若无 GPU，可在 CPU 上运行，但速度会慢很多。
